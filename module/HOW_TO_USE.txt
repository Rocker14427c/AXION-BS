HOW TO USE — Axion Super Power Saving v2.1
==========================================
ResukiSU (KernelSU). RMX3430 / AxionOS 2.7.

v2 difference vs 1.8:
- Snapshot of every node/prop/setting BEFORE any write
- Exit restores from those files (sysfs first, not settings-only)
- Does NOT freeze every app (that took 1–2 min and cooked the phone)
- Does NOT kill logd / persist.log.tag (Logfox keeps working)
- Does NOT deep-doze (that made the power button miss and 4–5s reboot)
- DT2W off only while SPSM is on; restored from snapshot on exit
- A55 cores stay online; A75 offline only while SPSM is on

INSTALL
1. ResukiSU → Modules → Install from storage → Axion-SPSM-v2.1-RMX3430.zip
2. Reboot.
3. App drawer → Super Power Saving
4. ResukiSU Superuser → Allow

TURN ON
1. Pick 6 apps. Turn on → confirm.
2. Should take a few seconds, not minutes.
3. Black 6-app home. Door top-left to exit.
4. Log: /data/adb/spsm/spsm.log  and  /data/adb/spsm/snap/MANIFEST

WHILE ON
- Power button wakes. DT2W is off (same as realme SPSM).
- Incoming calls / Jio VoLTE stay up. Mobile data stays on.
- Wi-Fi off while the screen is off.
- Google Play services sleep.
- logd stays running so you can record a log.

TURN OFF
- Door → Exit. Snapshot is restored. DT2W comes back if it was on.

STUCK
- ResukiSU → Modules → remove Axion Super Power Saving → reboot
- or: su -c 'sh /data/adb/spsm/exit.sh'
